# Project management context

BookRooms was approached as a small product-delivery project as well as a Rails application.

## From brief to delivery

The original brief called for a platform where users could browse discounted hotel rooms and make a reservation. The work was broken down into a delivery sequence covering:

1. Rails project setup
2. Data model and associations
3. Authentication
4. Hotel and room presentation
5. Booking workflow
6. Validation, testing and documentation

## Backlog and roadmap

The repository's [Issues](../../issues) record the product backlog and its feature sequencing. They are retained to show the planning approach used alongside implementation.

The application in this repository represents the implemented RNCP assessment scope. A few issue items describe potential next iterations and are intentionally kept as roadmap material rather than presented as completed features.
